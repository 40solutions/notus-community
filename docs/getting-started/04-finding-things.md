# Finding things

The main way to find a note again is Notus's full-text search.

## Search your notebook

Open search in any of three ways: click the **magnifying-glass button** at the top of the sidebar (opposite the Notus mark), choose **Edit → Find in All Notebooks…**, or press **Ctrl+Shift+F** (**Cmd+Shift+F** on macOS). Type a word or phrase, and Notus searches the notebook you have open — page titles and the text in your blocks, including labels such as a shape's or a diagram's. The sidebar button is available once a notebook is open; with none open there is nothing to search, so it stays disabled.

Each result shows which notebook, section, and page it came from, plus a short snippet of the matching text. Click a result to jump straight to that page.

## Marking lines with content tags

Search is for finding text you have written. To *flag* lines as you write — a to-do with a checkbox, an "important" marker, and seven others — use **content tags**, applied to the current line with **Ctrl+1** through **Ctrl+9** (**Cmd+1**–**9** on macOS). See the Search and Tags guide (in Notus: Help → Documentation → Search and Tags) for the full set.
