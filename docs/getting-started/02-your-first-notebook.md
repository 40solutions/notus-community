# Your first notebook

A **notebook** is where your notes live. Each notebook is a single file on your computer, and you can have as many as you like. Inside a notebook, pages are grouped into **sections**:

```
Notebook  →  Section  →  Page
```

## Create a notebook

From the **File** menu, choose **New Notebook…**. Notus asks you where to save the notebook and what to name it, then creates the file. The name you give the file becomes the notebook's name inside Notus; you can **rename the notebook** later by double-clicking its name (in Notus: Help → Documentation → Organizing Notebooks, Sections, and Pages) — renaming the notebook does not rename the file.

A brand-new notebook starts with one section, **New Section**, holding one empty page, **Untitled Page**. The page opens as a **blank canvas** with a hint in the middle — **double-click anywhere to add your first text block** and start typing (see [The Page Canvas](03-the-page-canvas.md)).

You can also create a notebook with **Ctrl+N** (**Cmd+N** on macOS), the shortcut shown next to **New Notebook…** in the File menu.

## Open an existing notebook

Choose **File → Open Notebook…** and pick a notebook file. Notus also keeps a list of recently opened notebooks under **File → Open Recent**, so you can reopen your usual notebooks quickly. Recent notebooks whose files have moved or been deleted are dropped from the list automatically.

You can have several notebooks open at once.

> **Note:** A notebook made by a newer version of Notus won't open on an older version — Notus refuses it rather than risk changing the file. If you see a message that a notebook was created by a newer version of Notus, update Notus to the latest version and try again.

## Sections and pages

Your open notebooks appear in the **sidebar** on the left, as an expandable tree of sections and pages. Working in the sidebar:

- **Rename** a section or page by **double-clicking** its name.
- **Add**, **delete**, and **move** each use a small control that appears when you hover over a row.
- **Reorder** sections and pages — and **move a page into another section** — by **dragging** them.
- **Right-click a page** for **Copy path** — which copies its location as `[Notebook]Section/Page` to the clipboard — and **Copy to notebook…**, which copies it into another open notebook. **Right-clicking a section** offers **Copy path** too (`[Notebook]Section`), and **Copy page from another notebook…**, which brings a page from another notebook into this one.

Deleting a section or page asks you to confirm first, and cannot be undone — so it is safe to click around.

## Start typing

On a new page, **double-click anywhere on the empty canvas** to create a text block at that spot and start typing. (A single click instead drops an **insertion point** — a marker showing where pasted content will land.) You are not limited to the top of the page: a page is a free 2D space, and you can place notes wherever you like.
