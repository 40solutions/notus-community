# Notus documentation

**The full Notus manual is built into the app.** In Notus, choose **Help → Documentation**. It works offline and covers everything — writing and formatting, shapes and diagrams, images and PDFs, search and tags, connectors, AI agents and more.

This folder has the basics, so you can read them before you install or link to them.
