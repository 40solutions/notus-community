# Notus

Notus is a desktop notebook for macOS, Windows and Linux. It works like a familiar notebook — notebooks, sections and pages — but every page is an infinite canvas: put text, images, PDFs, shapes and diagrams anywhere you like, side by side.

Notus is local-first. Your notebooks are ordinary files on your own computer, in a folder you choose, and the app works without an account or an internet connection.

With Notus Annual you can also bring live information onto your pages through connectors (email, calendar, Slack, databases, MQTT and more), and work alongside AI agents using your own AI provider account.

This repository is where you can report problems, suggest features and ask questions. It contains no source code.

## Getting help

- **In Notus:** choose **Help → Documentation**. The full manual is built in and works offline. Start with **Getting started**.
- **Here:** the [docs](docs/README.md) folder has the basics, a short [FAQ](docs/faq.md) and the [known issues](docs/known-issues.md) for the current version.

## Reporting a problem or asking a question

Open **[Issues → New issue](https://github.com/40solutions/notus-community/issues/new/choose)** and pick **Bug report**, **Feature request** or **Question**.

You can also start from inside Notus:

- choose **Help → Report an Issue…**, or
- ask a Notus agent, or Claude Code in a Coding Session, to draft the issue for you.

Either way, the issue opens on GitHub for you to review, and nothing is posted until you click **Submit**.

> [!WARNING]
> **Issues are public.** Never paste license keys, API keys, passwords, tokens or the contents of your notebooks into an issue. If you need to share a screenshot, check it first.
