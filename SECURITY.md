# Reporting a security problem

If you think you've found a security problem in Notus, please tell us privately. **Don't open a public issue.**

Email **contact@40solutions.com** with the subject **"Notus security"**, and include:

- your Notus version (**Help → About Notus**),
- your operating system and version,
- what you found and, if you can, the steps to reproduce it.

Please don't include license keys, API keys, passwords or other credentials in your email.

We'll acknowledge your report as soon as we can, and keep you posted while we look into it.
